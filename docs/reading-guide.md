# 安全与隐私：从威胁模型到研究设计的阅读路线

核验截止：2026-10-02。阅读按理解程度分阶段，进度由能否解释保护目标、方法和证据决定。可先从网页检测建立完整阅读习惯，再选择隐私学习或密码系统；无需把所有分支同时学完。基础概念见[综述](review.md)，文献状态与阅读范围见[代表研究](representative-research.md)。

## 阶段一：补齐最少的数学与数据背景

学习向量、内积、欧氏距离、条件概率、二分类交叉熵、训练/验证/测试分割、精确率与召回率。网页检测还需理解HTML与DOM树；隐私学习需理解随机机制、邻接数据和敏感度；协议研究需理解哈希、伪随机函数与秘密共享。

用综述中的三个小例子检查理解：给候选表示计算最近邻距离；计算计数查询的拉普拉斯噪声尺度；从TP、FP、FN计算F1。应能区分“看不到明文”“不能关联身份”“单个记录对输出影响有限”这三类保护目标。

## 阶段二：从可见的检测流程学会读方法

先读[无参考GNN钓鱼检测](../papers/P137.md)摘要与模型部分。画包含html、body、form、input结点的DOM树，说明结点、边和域名信息怎样影响二分类。其[公开PDF](https://tma.ifip.org/2025/wp-content/uploads/sites/14/2025/06/tma2025_poster1.pdf)可用于核对正文；具体出版日仍待确认。

接着读[SpecularNet](../papers/P136.md)的[arXiv论文](https://arxiv.org/abs/2603.01874)第3—5页与第8页。用两组箭头画子到父的编码与父到子的重建，解释为什么不依赖品牌参考库。整理一页对照：输入资源、结构表示、推理硬件、数据时间、规避攻击与非目标。

阶段检查：能说明训练集高分为何不能保证新模板有效；能区分召回率与低恶意基率下的部署精确率；能找到作者明确排除的攻击条件。

## 阶段三：选择一条主线深入

**隐私学习路线。** 先读[Dwork与Roth专著](https://www.cis.upenn.edu/~aaroth/Papers/privacybook.pdf)第2.3、3.3节，再读[PrivTune](../papers/P003.md)的[官方论文](https://arxiv.org/abs/2512.08809)第3—5、7—9页。画原始文本、表示与梯度的数据流，列出服务端知道和不知道什么。用最近邻例子解释反演，再核对扰动优化、随机噪声及令牌权重；不要把表示距离相关的$d_\chi$隐私直接等同标准数据库DP。

**密码系统路线。** 从[Path ORAM](https://arxiv.org/abs/1202.5150)理解“访问哪里也是信息”，再读[H2O2RAM](../papers/P038.md)第3—7、13页；[正式会议页](https://www.usenix.org/conference/usenixsecurity25/presentation/zheng)提供论文入口。区分服务器、TEE与客户端，把信任前提标在图旁。接着读[Gyges](../papers/P030.md)的[正式论文](https://dev.ndss-symposium.org/wp-content/uploads/2025-268-paper.pdf)第3—7、11—12页，解释预处理如何换取在线低通信，以及单轮匿名为何不覆盖跨轮交集风险。

阶段检查：能指出一个泄漏面、一个信任前提和一个成本指标，并给出正文位置。理解多个方向有帮助，深入阅读应先围绕一条清楚的问题主线展开。

## 阶段四：理解更新、后门与安全决策的不同目标

[合约持续学习](../papers/P001.md)的[预印本](https://arxiv.org/abs/2608.19680)第4—5、8—9页适合研究检测器如何学习新漏洞并保留旧知识。先以二维矩阵理解低秩适配，再分析回放与适配器合并。DIVE数据统计存在内部差异，未澄清前不据表推断独立样本量。

跨方向阅读可从[DEFUSE](../papers/P052.md)、[Platonic Defense](../papers/P055.md)及[PA-Attack](../papers/P061.md)中选一篇，分别区分输入级检测、净化和视觉编码器灰盒攻击。安全决策可选[网络欺骗中的博弈与基础模型](../papers/P148.md)、[猜测式在线学习](../papers/P151.md)或[5G零信任横向移动防御](../papers/P154.md)。先确认其是体系议程、决策算法还是部署实验，避免用一个类别的证据支持另一类结论。

## 阶段五：形成可检验的研究设计

选择时间与模板去重的检测评测、公开机制下的自适应反演评测，或多轮匿名关联风险中的一个问题。写出假设、数据来源、基线、控制变量、指标、失败判据和计算预算。研究假设即使不成立，也应能回答一个明确问题。

一篇论文的笔记包括：题目与版本、保护对象、攻击者可见与可控内容、可信组件、输入输出、方法图、关键公式及符号、数据划分、基线、效用与成本、明确非目标、正文页码。另将“论文事实”“作者假设”“待验证推测”分开。仅有题名或摘要的论文保留阅读层级，不补写未读算法与结果。
